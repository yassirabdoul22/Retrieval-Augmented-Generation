RAG against the machine — v2.0

Naive RAG pipeline, with room for the bonus layer

Four mandatory stages run left to right on the vLLM 0.10.1 corpus. The dashed track underneath is optional: semantic embeddings and hybrid fusion slot in without touching the lexical path.

mandatory · lexical mandatory · generation optional · bonus

Why two chunkers

Code and prose break apart differently. .py files split along function/class boundaries; .md files split along headings and paragraphs. Both cap at --max_chunk_size (2000 chars) — the grader rejects any source longer than that.

What stays swappable

A Retriever interface with .index() / .retrieve() lets BM25 ship first. The bonus track (embeddings, hybrid) plugs in later as a second implementation — no rewrite of retrieval or generation needed.

The evaluate loop

The dashed branch back from retrieval is your own evaluate command — local recall@k for iteration. The graded score comes only from the external moulinette binary, never called from your code.

src/index → src/search(_dataset) → src/answer(_dataset) → moulinette evaluate_student_search_results
